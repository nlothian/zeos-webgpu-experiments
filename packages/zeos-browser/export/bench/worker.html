OptZeosWorker on WebGPU

Checks and times web/opt_zeos_worker.js through the ZeosModelWorker interface. Query parameters: model (default /models/Qwen3.5-4B-ZEOS-OPT/), ort (the ort.webgpu.min.mjs to import), steps (greedy steps, default 32). Serve the demo directory (node tests/opt_zeos_webgpu.mjs serves it) after npm install.
