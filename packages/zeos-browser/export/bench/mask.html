Masked tool names on WebGPU

Times web/opt_zeos_worker.js choosing tool names with the tool results hidden (mask_tool_choice), in a chat-agent context of about 7,000 tokens. Query parameters: model (default /models/Qwen3.5-4B-ZEOS-OPT/), ort (the ort.webgpu.min.mjs to import), system (tokens in the system turn, default 6700). Run by node tests/opt_zeos_webgpu.mjs --page mask.html, after npm install.
